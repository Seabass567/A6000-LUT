# rx100 branch

This fork's `rx100` branch adapts A6000-LUT for a Sony RX100 III (DSC-RX100M3). It's built and installed from
[Seabass567/rx100-lab](https://github.com/Seabass567/rx100-lab) (`tools/build-lut.sh`, `tools/install.sh custom-lut`),
which compiles against OpenMemories-Framework's stubs instead of ones pulled off a camera.

Changes from upstream, all in `MainActivity.java`, each marked `rx100`:

- **Support check.** Right after the camera opens, the app asks `ParametersModifier.isExtendedGammaTableSupported()`
  and `isRGBMatrixSupported()`. The answer goes to `LUTS/LUTCACHE/PREPLOG.TXT`. If either is missing, or the check
  itself throws (a method this firmware lacks), the app says so on screen and never writes the pipeline.
- **Keys.** Choose also takes the rear wheel (scan codes 522/523); strength also takes four-way left/right (105/106)
  and DIAL_3 (635/634). Bodies without the A6000's two dials keep a route for both.
- **English on screen.** The 14 on-screen strings. Code comments stay as upstream wrote them.

Untested on an RX100 III: nobody has run it on one yet.
